# 🐱🎀 Мурчат — готовые сборки

Здесь лежат только готовые версии программы «Мурчат» для Windows
(выгрузка переписок из Telegram в файлик, чтобы показать их ИИ).

## 💖 Скачать

**[⬇️ Скачать последнюю версию (Murchat-windows.zip)](https://github.com/ricxrdelo/murchat-releases/releases/latest/download/Murchat-windows.zip)**

1. Распакуй архив.
2. Открой папку «Мурчат» и запусти «Мурчат.exe».
3. Нажми «Войти в Telegram» и отсканируй QR-код телефоном.

Подробная инструкция — в файле `ИНСТРУКЦИЯ.txt` внутри архива.
Новые версии программа находит и ставит сама ✨
